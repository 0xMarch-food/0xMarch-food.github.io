Agent 可以看成能交互与任务执行循环的外壳，壳里面挂载大模型、记忆、工具。这个壳只负责流程调度，大模型负责思考决策。

比如ClaudeCode+deepseekV4pro就是说ClaudeCode这个外壳接入ds大模型。

比如Nuwax就可以搭建自己的智能体。
https://agent.nuwax.com
用户使用手册
https://nuwax.com/user-manual.html

NUWAX平台现在把智能体大致分成：

  • 问答型 Agent
  • 通用型 Agent
  • AgentFlow
  • AgentGroup

在Nuwax里面，Agent 是员工，AgentGroup 是一个团队，AgentFlow 是团队的SOP流程图。

System Prompt 系统提示词：定义Agent角色、能用什么工具，属于底层预设，用户看不见，最先给到模型。
User Prompt 用户提示词：就是用户发出去的问题、指令。

工作流：一套预先规定好任务先做什么、再做什么、分支怎么走、循环多少次的执行流程。
